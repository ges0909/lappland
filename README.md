# Lappland Reiseplanung (Finnland)

Umfassender Variantenvergleich und Recherche-Richtlinien für eine 7-tägige Reise nach Finnisch-Lappland (Levi & Rovaniemi) im Frühwinter.

## Dokumente

* **[lappland-reisevarianten.md](lappland-reisevarianten.md):** Ausführlicher Vergleich der Reisevarianten, Flugoptionen (Finnair, Lufthansa, Eurowings, easyJet), Unterkünfte, Loipenbedingungen (First-Snow / Snowfarming), arktische Aktivitäten und Fazit.
* **[recherche-richtlinien.md](recherche-richtlinien.md):** Verbindliche Parameter, Reiseprofil (65 Jahre, sportlich aktiv, Komfortzeiten), Metasuch- und Erhebungsstandards für KI-Assistenten und Preisaktualisierungen.
